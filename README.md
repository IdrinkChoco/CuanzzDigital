💸 Money Manager (Supabase Edition)
Selamat datang di Money Manager Single HTML + Backend Supabase — aplikasi manajemen keuangan yang kelihatan sederhana, tapi diam-diam punya server sendiri.

🎉 Kenapa spesial?
🗂️ Frontend cuma satu file HTML: gampang dibuka, gampang ditutup, gampang ditinggalin.
🛠️ Backend Supabase: biar data nggak cuma numpang di localStorage, tapi bisa hidup di server yang kamu host sendiri.
📊 Catat pengeluaran: dari kopi, skincare, sampai gacha Axie.
💰 Pantau pemasukan: biar bisa bilang “aku kaya… di database Supabase”.
🧮 Saldo otomatis: hitungannya lebih cepat daripada kamu sadar gaji sudah habis.

🚀 Cara Pakai
Clone repo ini.
Buka index.html di browser (kalau masih pakai IE, upgrade dulu 🙏).
Pastikan Supabase sudah jalan di backend.
Isi pemasukan dan pengeluaran.
Lihat saldo, lalu tentukan apakah perlu side hustle baru atau jualan kopi.

🐛 Bug?
Kalau ada bug, anggap itu fitur.
Kalau ada fitur yang kurang, anggap itu bug.
Kalau saldo minus, itu bukan bug, itu realita.
